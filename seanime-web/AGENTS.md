# Seanime Web Agents

Seanime web is the single UI for every Seanime client. It is a React 19 SPA built
with **rsbuild** (Rspack) and routed by **TanStack Router**. There is no Next.js and
no desktop target — the project ships the Go server plus this web UI only.

## At-a-glance

| Agent | Scope | Key Paths | Runtime | Typical Commands |
| --- | --- | --- | --- | --- |
| App Shell | Routing, layouts, providers | `src/routes/`, `src/app/` | React 19, TanStack Router | `npm run dev` |
| Feature Modules | Domain-specific UI, hooks, state | `src/app/(main)/_features/**` | React 19, TanStack Query, Jotai | Co-located with features |
| API Client (generated) | Typed API access to Go handlers | `src/api/generated/**` | TypeScript (codegen) | `go run main.go ...` in repo-root `codegen/` |
| Shared UI System | Design system, forms, primitives | `src/components/**` | Radix UI, Tailwind 4 | Consumed across features |
| State & Utils | Global atoms, helpers | `src/app/(main)/_atoms/**`, `src/lib/**` | Jotai, TypeScript | Imported by features |
| Build | Bundling and env targets | `rsbuild.config.ts`, `.env.web`, `.env.mobile` | rsbuild / Rspack | `npm run build` |
| Testing | Unit tests | `src/**/*.{test,spec}.{ts,tsx}` | Vitest | `npm run test` |

## Routing

Routing is file-based over **two** directories, a shape left by the migration off
Next.js:

- `src/routes/` — the route files TanStack Router discovers. Most are thin: they
  call `createFileRoute(...)` and point `component` at something in `src/app/`.
  `src/routes/_main.tsx` is the authenticated shell; `src/routes/_main/*` are its
  children; `src/routes/public/*` is the unauthenticated side.
- `src/app/` — the actual page and feature components, still using the Next-style
  `(main)` group and `page.tsx` naming. These names are conventional only; they
  carry no routing meaning here.
- `src/routeTree.gen.ts` — generated by `TanStackRouterRspack` (see
  `rsbuild.config.ts`) on dev/build. Never hand-edit it; add or remove a file in
  `src/routes/` and rebuild.

## Feature Modules

Each directory under `src/app/(main)/_features/` is a functional slice (library,
torrent control, manga reader, video-core player, plugin host). Patterns:

- `*.tsx` components backed by hooks in `*.hooks.ts` or `_lib/handle-*.ts`.
- Shared state via Jotai atoms in `_atoms/`, server state via TanStack Query.
- Tailwind utilities for styling.

## API Client (generated)

Files in `src/api/generated/` are produced from the Go backend. Never hand-edit
them. After changing a Go handler, its request/response structs, or a public struct
a handler returns, regenerate from the repo root:

```
cd codegen && go run main.go --skipHandlers=false --skipStructs=false --skipTypes=false \
  --skipPluginEvents=true --skipHookEvents=true --skipHandlerHookEvents=true
```

This is network-free (it parses Go source) and rewrites `types.ts`, `endpoints.ts`,
`endpoint.types.ts` and `hooks_template.ts`. `hooks_template.ts` is a commented
scaffold only — the React hooks in `src/api/hooks/*.hooks.ts` are hand-written;
add new ones there by mirroring an existing hook.

## Credentials

The server withholds stored credentials (media-player and torrent-client passwords,
debrid and translation API keys, both Nakama passwords) from every settings payload
and sends `REDACTED_SECRET` in their place — see `src/lib/server/secrets.ts` and
`internal/database/models/redact.go`. Settings forms round-trip the placeholder
unchanged, which the server reads as "leave this credential alone".

Consequences for anything touching these values:

- Check `isRedactedSecret()` before consuming a settings value as a credential
  rather than echoing it back.
- Render every credential input with `type="password"`. The issue reporter records
  the DOM with `maskInputOptions: { password: true }`, so it masks by input *type*
  — an unmasked field is captured verbatim into a session replay users attach to
  public bug reports.
- Never put a credential in a URL. The `/events` websocket sends a short-lived
  ticket from `/api/v1/auth/ws-ticket`, and media URLs use scoped `?token=` tokens,
  precisely so the credential itself stays out of proxy logs.
- Never log an `AxiosError` object; its `config.headers` carries `X-Seanime-Token`.
  Use `describeSeaError()` in `src/api/client/requests.ts`.

## Build Targets

`.env.web` and `.env.mobile` set `SEA_PUBLIC_PLATFORM`, which reaches the app as
`__clientPlatform__` (`src/types/constants.ts`). Scripts:

- `npm run dev` — rsbuild dev server with `.env.web`
- `npm run dev:mobile` — same with `.env.mobile`
- `npm run typecheck` — `tsgo`
- `npm run build` — typecheck, then `rsbuild build` into `out/`
- `npm run test` — Vitest

The Go server embeds the built UI from the repo-root `web/` directory; `out/` is
copied there as a packaging step. Don't edit `web/` by hand.
